# Library Management Tools (`library-tools`)

Automated collection of standalone Windows utilities (`.exe`) built daily to simplify library management workflows (catalog indexing, ISBN validation, loan & due-date tracking, shelf labeling, overdue reporting, and inventory audits).

## Tools Index

| # | Folder | Executable | Description |
|---|--------|------------|-------------|
| 01 | [`01-library-quick-desk`](./01-library-quick-desk) | `LibraryQuickDesk.exe` | Desktop & CLI utility for ISBN-10/13 validation, book checkouts, due-date calculation, and overdue reporting. |
